**Threat.** A program running as the user signs management requests with the DPAPI device key and
mints placeholders, elevates a lease or asks for GitHub App tokens without a gesture.

**Today.** `/placeholder`, `/elevate` and `/token` need an approval signed with the lease's approval
key, derived from the Hello wrap and registered only by a seal whose DEKs open the vault
([design](../step-up.md)). The broker builds the operation from the approval alone and refuses a
replay. What remains: the unlocked app holds the wrap key in memory, and a program at the same
integrity level can click Allow in the app's consent dialog.

**Closes it.** Moving the unlocked agent out of the user's session (the Windows service).
