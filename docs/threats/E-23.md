**Threat.** `tir elevate` and `tir grant` ask for a fresh Hello gesture on the workstation, but the
broker checks only the DPAPI device signature. A program running as the user can sign the same
requests and mint placeholders, elevate a lease or ask for tokens without a gesture.

**Today.** The Keyring's own commands demand Hello; the broker README lists this as *Step-up is local
only*.

**Closes it.** The broker requires a TPM-backed approval it verifies itself for privileged actions
([design](../step-up.md)).
