---
id: S-41
title: A program running as the user can add a device key to the trust chain
stride: Spoofing
likelihood: 3
impact: 4
status: open
issue: 41
control: ASVS V6 Authentication
---

**Threat.** Trust-chain links are authorized by Ed25519 device keys that DPAPI protects to the
user's account, with no user presence. A program running as the user can sign an `AddDevice` (or,
on an administrator's device with the default threshold of 1, an `AddUser`) introducing a key of its
own, and post it to the broker. That key can leave the machine and outlives the program's removal.

**Today.** No Tiresias flow builds these links, but the verifier and `POST /trust/chain` accept
them. In solo mode the broker listens on loopback only, which limits the new key to this machine.

**Closes it.** Links that add trust carry a Windows Hello signature from every authorizing and every
new device, anchored at genesis by the paper key ([design](../trust-links.md)).
