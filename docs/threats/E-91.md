---
id: E-91
title: A program running as the user uses the admin tier's SYSTEM service to gain privilege or undo protection
stride: Elevation of privilege
likelihood: 2
impact: 4
status: open
issue: 91
control: ASVS V8 Authorization
---

**Threat.** The optional admin tier ([admin-tier.md](../admin-tier.md)) runs a service as SYSTEM
and takes requests over a pipe any signed-in user can open. Malware running as the user tries to:
replace the service's binary; send a request that makes SYSTEM write, read or run something of its
choosing; thaw a frozen program or lift its network block; read the decoys back; act on another
user's processes; or create the pipe before the service does and pose as it to the app.

**Today.** Not built. The design closes each path:

- The binary is copied to `%ProgramFiles%` and its state kept in `%ProgramData%` with an ACL of
  SYSTEM and Administrators only; nothing runs from the per-user install folder.
- A fixed list of typed actions, no paths to run and no generic file or registry access; anything
  unknown or out of range is refused before acting.
- Every action that weakens protection (`thaw`, `decoys.release`, `teardown`) needs an elevated
  caller, which takes a UAC prompt the user's programs can't click.
- Every action is keyed by the caller's user SID from the pipe's client token: a caller reaches only
  its own user's processes, decoys and events.
- The app checks that the pipe's server process is the one the Service Control Manager runs.
- SYSTEM never writes into a user's profile; reading the decoy files' attributes opens them without
  following reparse points.

**Residual.** The install step itself runs from the per-user folder, elevated: a program that
replaced `Tiresias.exe` there gets elevated when the user approves the prompt. That is the same as
any per-user app that asks for elevation; the UAC prompt shows the publisher. Whether a job freeze
withstands `NtResumeProcess` from the user's own token is to be checked before step 4.

**Closes it.** Built as designed, with tests for the caller rules, then a review of the service's
code by someone other than its author.
