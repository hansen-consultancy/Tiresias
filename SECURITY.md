# Security policy

Tiresias protects credentials, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Use GitHub's private vulnerability
reporting instead ("Report a vulnerability" on the Security tab of this repository).

Expect an acknowledgement within a few days. Fixes ship as a new preview release, with credit
unless you ask otherwise. Only the latest release is supported while the project is in 0.x.
